# AGENTS.md

This file provides guidance to AI coding agents when working with code in this repository.

## Project

Memory Lights (`:app`, package `com.happypuppy.memorylights`) is a classic Simon-style memory game built with Kotlin, Jetpack Compose + Material 3, DataStore Preferences, Koin, and type-safe Navigation Compose. Supports Classic & Speed Blitz modes, 4-button Standard and 6-button Memory Lights+, Reverse/Practice/Audio-Only/Daily Challenge/Color-Blind modes, 7 sound packs, statistics, and achievements. `minSdk 31`, `compileSdk 37.1`, `targetSdk 36`, AGP `9.5.3`, Gradle `9.9.2`, Kotlin `2.4.21`.

## Commands

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest   # local CI verification
./gradlew testDebugUnitTest                                                    # JVM unit tests only
./gradlew lintRelease bundleRelease -PversionCode=N -PversionName=X.Y.Z        # signed release AAB

```

## Build, versioning and release

- `versionCode`/`versionName` default to `1` / `1.0` in `app/build.gradle.kts` and are overridden by `-PversionCode`/`-PversionName` or `VERSION_CODE`/`VERSION_NAME` env vars. Always use clean semantic `versionName` (never commit hashes — see `../cicd/AGENTS.md`).
- Release builds enable R8, resource shrinking, `ndk.debugSymbolLevel = "SYMBOL_TABLE"`, and fail the build if `targetSdk < 36` (Play policy gate in `app/build.gradle.kts`).
- Local signing reads `keystore.properties` (git-ignored) or `ANDROID_KEYSTORE_*` env vars; never commit keystores, `keystore.properties`, or service-account files.
- `app/src/main/play/release-notes/` is generated by the local release pipeline from commit subjects and is git-ignored.
